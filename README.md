# Poketour

송파구 실제 지도에서 이동·전투·포획·성장을 즐기는 웹 게임입니다. 2026-10-23 사용자의 명시적 요청에 따라 최신 소스와 실행 파일을 vvoosol/poketour main에 동기화했습니다.

## 내 PC에서 실행

최상위 `index.html`을 브라우저로 열면 됩니다. 옆의 `assets/` 폴더를 함께 유지하세요. 파일 실행용 데이터와 게임 저장 모듈을 함께 제공하므로 Node.js나 실행 명령이 필요하지 않습니다. 지도 타일에는 인터넷 연결이 필요합니다.

웹 주소 방식으로 확인하려면 Node.js 24가 설치된 PC에서 `로컬실행.cmd`를 실행한 뒤 http://127.0.0.1:5174/ 를 엽니다. 파일 실행과 GitHub Pages는 브라우저 저장 영역이 다르므로 진행도를 옮길 때 메뉴에서 저장 파일을 내려받아 복원하세요.

## GitHub에 직접 업로드

게시할 폴더에 최상위 **`index.html`과 `assets/` 전체를 함께** 올립니다. 폴더 구조를 유지하세요. `index.html`만 올리면 작동하지 않습니다. GitHub Pages 주소로 공유합니다. 이전 공유 주소는 https://vvoosol.github.io/poketour-play/ 입니다. 사용자의 선택에 따라 vvoosol/poketour를 공개로 전환하고 Pages를 활성화했습니다. 새 게임 주소는 https://vvoosol.github.io/poketour/ 입니다. main의 index.html/assets 변경을 GitHub Actions가 자동 배포합니다.

`songpa-site`는 개발 원본입니다. 실행에 의존성 폴더, 로컬 DB나 서버 번들은 필요하지 않습니다. 업로드·배포는 사용자의 명시적 요청 범위에서 수행합니다.

## 개발과 검증

화면은 세로 **9:20**, 가로 **20:9** 두 가지 배치로 고정했습니다. 화면 크기가 바뀌면 배치를 유지하고 전체 배율만 바뀝니다. [화면 배치 기준](docs/UI_LAYOUT.md)을 참고하세요.

메뉴 → ‘모험 안내 · 목표’에서 안내와 1회 보상을 확인합니다. 탐험 팀 → 보관함에서 이름·번호 검색, 상태 필터와 정렬을 사용할 수 있습니다. [3단계 적용 내용과 측정 결과](docs/STAGE_3.md)를 참고하세요.

지도 자동전투는 100m 안에서 첫 공격 기술을 교환하고 체력 10배를 적용합니다. 수동전투는 기본 체력과 네 기술 슬롯을 사용합니다. 지도 야생은 전투 상대를 포함해 최대 5마리이며, 새 출현 시 이동 대상·전투 상대를 보호하고 가장 오래된 개체부터 교체합니다. 공원 주변은 가까운 출현을 2분/90%로 보정합니다. 메뉴에서 지금 저장·백업·복원·진행도 초기화를 할 수 있습니다. [현재 전투·출현·저장 규칙](docs/FIELD_COMBAT.md)을 참고하세요.

전투 결과를 순서대로 재생하며 머드나기·찌리비·맛보돈의 실제 동작을 지도에 연결했습니다. 공격·피격·HP 감소·기절을 함께 표현하며, 나머지 종은 기존 이미지와 기본 효과를 사용합니다. 1초 정산은 화면을 잠그거나 알림을 반복하지 않습니다. 메뉴의 데이터 설명에서 ‘전투 동작 미리보기’를 열 수 있습니다. 수동전투는 상대 우상단·아군 좌하단 무대, 싸운다/가방/포켓몬/도망과 네 기술 선택으로 개편했습니다. 미확보 뒷모습은 정면으로 대체합니다. [전투 연출 구현 진행](docs/COMBAT_IMPLEMENTATION.md)을 참고하세요.

```sh
cd songpa-site
npm ci
npm run build
npm test
```

원본은 최상위 `index.html`과 `songpa-site/src/`, `songpa-site/public/`에 있습니다. 빌드는 `songpa-site/dist/`를 생성하고 최상위 `assets/`도 갱신합니다. 생성 파일을 직접 수정하지 않습니다. `dist/client/`도 별도의 완성된 정적 배포 폴더입니다.

진행도는 이 브라우저의 IndexedDB에 저장됩니다. 다른 기기로 옮길 때 메뉴의 저장 파일 내보내기·복원을 사용하세요. 기존 서버 계정 저장은 자동 이전되지 않습니다. `npm run dev`·`npm run preview`는 서버 회귀 검사용이므로 정적 실행 확인에는 위 `로컬실행.cmd`를 사용합니다.
