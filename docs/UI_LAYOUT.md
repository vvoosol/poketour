# 고정 휴대폰 화면 구성

화면은 세로 9:20(360×800 논리 픽셀), 가로 20:9(800×360 논리 픽셀) 두 가지다. 기기 방향에 따라 배치를 선택하고 화면에 들어가는 공통 배율로 전체를 확대·축소한다. 남는 공간은 여백으로 둔다. 창 너비에 따른 열 수·글자 크기·버튼 크기 변경은 사용하지 않는다.

세로는 상단 자원 표시, 이동 정보, 지도, 상태 안내, 하단 5개 메뉴 순서로 구역을 나눈다. 스타팅 선택 중에는 지도 아래에 선택 영역을 확보한다. 게임 패널은 상단 정보와 하단 메뉴 사이에서만 스크롤된다.

가로는 상단 자원 표시, 왼쪽 지도, 오른쪽의 좁은 세로 이동 정보, 맨 오른쪽 5개 메뉴로 나눈다. 지도는 576×244 논리 픽셀이고 오른쪽 112픽셀 열에 남은 시간과 도착 예정을 위아래로 쌓는다. 스타팅 선택 중에만 지도 아래에 선택 영역을 확보한다. 가방·도감은 가로에서 4열, 세로에서 2열을 사용하며 각 방향 안에서는 열 수가 고정된다.

주변 장소 상세는 세로에서는 목록 아래, 가로에서는 목록 오른쪽에 배치한다. 시설 활동을 열면 상세 대신 활동 영역을 표시한다. 상태 안내와 위치 추적 버튼·지도 출처의 공간을 따로 확보한다. 지도 확대·축소·전체 버튼은 기능 활성화 전까지 숨긴다. 시설 기호는 20×20, 기호 글자는 12, 장소 이름은 8 논리 픽셀로 두 방향에서 동일하게 표시한다.

화면 기준은 `src/client/layout.css`, 확대·축소와 방향 선택은 `src/client/layout.js`에서 관리한다. 휴대폰의 화면 방향 정보가 있으면 키보드가 올라와도 방향을 바꾸지 않는다. 방향 변경 시 지도 크기를 다시 계산한다.

검증은 `npm run build` 후 `npm test`로 수행한다. 배율·논리 크기 검사는 실제 브라우저의 글자 줄바꿈·지도 입력·터치 검증을 대신하지 않는다.

하단/오른쪽 고정 메뉴 순서는 지도·탐험 팀·가방·전투·메뉴다. 도감은 모험 메뉴에서 연다. 상점 상품은 지도에 등록된 상점/백화점에 게임 위치가 도착한 뒤 해당 시설 활동에서만 표시하며, 출발하면 닫힌다.

수동전투는 세로에서 위쪽 290픽셀 전투 무대와 아래쪽 명령 영역, 가로에서 왼쪽 440픽셀 무대와 오른쪽 명령 영역으로 고정한다. 상대는 우상단, 아군은 좌하단이며 HP 창을 각각 분리한다. 네 명령과 네 기술은 두 방향 모두 2×2다. 긴 도구/교체 목록은 명령 영역 안에서 스크롤한다. 지도 야생 정보 팝업은 지도 상단 중앙에 표시해 짧은 가로 화면에서도 이동 확인 버튼을 누를 수 있게 한다.
