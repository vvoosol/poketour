# 진행 기록

## GitHub Pages 전환

사용자의 최신 요청에 따라 공유·실행을 GitHub Pages와 최상위 index.html 방식으로 변경한다. 기존 호스팅과 로그인 의존성은 실행 코드에서 제거하고 과거 자료는 docs/archive로 옮겼다.

- 개발 원본: vvoosol/poketour (비공개 유지).
- 공개 실행 파일 전용 저장소: vvoosol/poketour-play.
- 기존 비공개 저장소의 Pages 생성은 현재 요금제 미지원으로 HTTP 422 응답을 받았다.
- 기본 빌드는 로그인 없는 browser 모드이며 API 행동을 IndexedDB 트랜잭션과 공유 엔진으로 처리한다.
- 다중 탭 revision 비교, 최근 requestId 재전송 방지, 상태와 사건의 원자적 저장, 기존 개체 UID·HP migration을 유지한다.
- 도보 A* 그래프는 경로 요청 때만 내려받아 브라우저에서 계산한다.
- 저장 파일 내보내기·검증 후 복원을 추가했다. 다른 브라우저/기기 자동 동기화와 서버 시각 기반 권한 보장은 없다.
- Pages 실행 파일은 상대 경로로 동작하며 GPT 로그인 링크·API·호스팅 주소를 호출하지 않는다.
- 기존 로컬 SQLite 서버는 선택적 회귀 환경으로 보존하며, 사용자 신원은 로컬 어댑터 함수로만 공급한다.

### 검증

최종 npm run build 및 전체 npm test를 실행했다. 기존 게임/기하·경로·SQLite API·모의 DOM·로컬 HTTP 검사를 유지했고 fake-indexeddb로 브라우저 저장 재열기, 동시 탭 충돌, 경로 계획/출발/취소, 사건 기록, 백업/복원, 잘못된 파일 거절과 서로 다른 저장소 분리를 확인했다.

실제 Pages 주소는 `https://vvoosol.github.io/poketour-play/`다. 외부 HTTP 200과 실행 자산 로딩을 확인했고, 실제 브라우저에서 로그인 없이 머드나기 선택과 새로고침 후 진행도 유지를 확인했다. 화면 확인 중 발견한 하단 메뉴의 top/bottom 충돌도 수정했다. 최종 배포 정보는 docs/SHARING.md에 기록했다.

새 주소 확인 후 기존 사이트의 공개 접근은 종료하고 기존 서버 저장은 소유자 전용으로 보존했다. 실제 휴대폰 GPS·터치 검증은 아직 수행하지 않았다. 이전 서버 저장은 자동 이전하지 않으며 파괴하지 않는다.

## 2026-10-20 index.html 직접 열기 지원

- 사용자가 보낸 화면은 이전에 추가한 file:// 실행 차단 안내였다. 해당 화면 교체 코드를 제거했다.
- 파일 실행에서만 file-mode.js를 먼저 로드한다. 기존 브라우저 저장 모듈·공유 엔진을 classic IIFE로 묶고 필수 JSON과 보행 그래프를 포함하여 fetch(file://) 및 ES module 접근을 없앴다. HTTP/HTTPS는 기존 지연 로드 방식을 유지한다.
- 최상위 index.html과 assets 전체를 다시 생성했다. Node.js 없이 파일을 여는 경로를 제공하며 지도 타일은 인터넷이 필요하다. file://와 HTTPS 저장은 자동 공유되지 않으므로 저장 파일로 이전한다.
- npm run build 및 전체 npm test 통과. 새 VM 검사는 실제 생성 번들/플랫폼으로 시작·스타터·A* 경로·이동/취소·IndexedDB 재열기·백업/복원을 검사한다. 실제 브라우저 시각 검증은 도구의 file:// URL 보안 정책 차단으로 수행하지 못했다. 다른 브라우저나 우회 경로는 사용하지 않았다.
- 로컬 파일만 수정했다. 원격 커밋·푸시·배포 없음.
