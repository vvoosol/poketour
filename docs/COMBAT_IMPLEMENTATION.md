# 전투 연출 구현 진행

2026-10-22. GitHub 업로드는 사용자 직접 수행. 현재 1~3단계에 이어 4단계 수동전투 명령 화면과 전투 무대를 연결했다. 자동 체력은 10배로 변경했다.

## 1단계: 전투 사실과 재생 분리

- 엔진이 `kind: combat` 사건을 남긴다. battleId/turnId/sequence, 공격자·대상 UID, 기술, 명중/실패/무효, HP 전후 값, 종·레벨·배율·상태·좌표 스냅샷을 포함한다. 공격·행동 불가·회복·반동·상태 변화/피해·교체·기절·볼 시도·전투 종료를 순서대로 기록한다. 기존 일반 로그와 저장의 원자성은 유지한다.
- 공통 `combat-playback.js`는 사건을 순서대로 보여 주며 RNG·피해·아이템·보상을 계산하지 않는다. 이미 받은 사건/오래된 revision은 다시 재생하지 않는다. 새로고침·복원·탭 복귀·오프라인 정산은 확정 상태에 맞춘다. 초기화는 재생 큐를 폐기한다. 표현 오류와 3.5초 제한 이후에도 입력 잠금을 해제한다.
- 브라우저에서 타이머가 잘못된 수신 객체로 호출되던 오류를 수정했다. Node가 허용하고 브라우저가 거절하는 타이머 호출 조건을 별도 VM 검사에 넣었다. 자동/수동 전환 대기는 재생 종료 순간 저장 요청이 진행 중이어도 보존하고 저장 완료 뒤 처리한다.
- 현재 지도/수동 화면의 표시 HP를 실제 HP와 분리해 감소 과정을 보여 준다. 최종타 뒤 기절·종료 사건까지 상대를 잠깐 유지한다. 전투 명령은 재생 중 잠그고 자동/수동 변경은 재생 종료 뒤 요청한다. 수동 화면의 본가 형태 개편은 아직 하지 않았다.
- 반동으로 한쪽이 기절한 뒤 다른 쪽이 추가로 공격하던 문제를 수정했다. 기존 우선도·스피드·명중·PP·6초·HP 배율은 유지한다.
- 실제 브라우저 확인에서 MapLibre 야생 마커가 `setLngLat()` 없이 `addTo()`되어 오류와 표식 중복이 발생하는 것을 발견했다. 좌표를 먼저 설정하도록 고쳤으며 모의 지도도 이 순서가 틀리면 실패하도록 보강했다. 연출의 짧은 갱신 주기에서 진행 중인 지도 카메라 이동을 계속 재시작하지 않도록 했다.

## 2단계: 기본 동작 자료와 효과

- PMDCollab/SpriteCollab 고정 커밋 `0250bd6e62029bb896276a7f6bcb2385ed1a02f0`에서 머드나기(749)·찌리비(940)·맛보돈(915)의 5개 실제 동작(Idle/Walk/Attack/Shoot/Hurt)을 준비했다. PNG 45개는 원본 그대로이며, XML·방향·프레임 지속 시간·중심/발 기준점만 manifest로 변환했다.
- Ichor/bwappi, Soulja/DavKriz, Emboarger의 크레딧과 PMDCollab_1/PMDCollab_2/CC BY-NC 4.0 자료를 함께 보관한다. 메뉴의 데이터 설명에서 출처 페이지를 열 수 있다.
- 샤프니아(318)는 조사한 기본 자료가 CHUNSOFT/Unspecified여서 신규 동작 시트를 가져오지 않았다. 기존 이미지와 기본 효과를 사용한다. 나머지 미확보 종도 같은 대체 경로를 사용한다.
- 세 종 모두 전용 Faint 시트가 없어 Hurt와 투명도 감소로 대체한다. 방향 시트의 북쪽 모습은 지도용 뒷방향이며 본가 전투의 전용 뒷모습 자료로 표시하지 않는다. 전용 색이 다른 개체 시트는 포함하지 않았다.
- `pokemon-animator.js`는 동작·방향·프레임·발 기준점으로 Canvas에 그린다. 이미지 중복 로딩을 피하고 실패한 자료는 다시 읽을 수 있다. 메타데이터는 JS와 JSON을 함께 제공해 file:// 미리보기에 fetch가 필요하지 않다.
- `move-effects.js`는 접촉/할퀴기/불/물/풀/전기/에너지/상태 효과를 구분한다. Showdown의 CC0 개별 기술 파일에서 선택한 별칭·시간 패턴을 작은 테이블로 변환하고 그림 대신 자체 Canvas 도형으로 표현한다. 전체 Showdown 엔진·화면·그림·음향은 포함하지 않았다. 지정 기술 이외는 공통 효과이며 전용 연출 완성으로 계산하지 않는다.
- `scripts/prepare-combat-assets.py`는 선택 자료 다운로드/변환용이며 일반 빌드에는 Python/네트워크가 필요하지 않다. 원본 XML·크레딧은 source-data/combat, 실행 파일은 public/combat에 둔다.

## 확인 방법

게임 메뉴 → 데이터·선정 기준·개인정보 → **전투 동작 미리보기**. 또는 배포 파일의 `assets/combat/preview.html`을 연다. 포켓몬·동작·방향·기술 효과와 다시 재생을 선택한다. 이 페이지는 지도에 쓰이는 동작과 미확보 종의 대체 표시를 따로 확인하는 도구다.

## 3단계: 지도 동작 연결 및 화면 갱신

- `map-combat-view.js`가 MapLibre 마커 안의 작은 Canvas를 유지하며 Idle/Walk/Attack/Shoot/Hurt와 기절 표현을 재생한다. 지도 마커 자체의 위치 변환은 건드리지 않는다. 머드나기·찌리비·맛보돈은 실제 프레임, 미확보 종은 기존 PNG의 돌진·흔들림·투명도 효과를 쓴다. 이미지 로딩 실패 때도 기존 그림을 표시한다.
- 공격자의 방향과 타격 프레임, 기술별 투사체/접촉 효과, 상대 피격과 HP 감소를 같은 타격 시점에 맞춘다. 미리 표시한 피해는 다음 HP 사건에서 중복 표시하지 않는다. 빗나감/무효는 피격 효과와 구분한다. 최종타 이후 상대를 유지해 기절을 보여 준 뒤 제거한다.
- 화면 크기 변화와 지도 이동 중 매 프레임 현재 마커 위치를 읽어 효과와 HP 위치를 맞춘다. 트레이너·동행·야생 전체의 그림 간격을 확보하며 실제 좌표와 사거리 계산은 바꾸지 않는다. 마커 안의 버튼/동행 홀더를 함께 옮겨 그림·클릭 영역·HP·효과 좌표를 일치시키고 Canvas 안에서 큰 간격을 억지로 그리다 잘리는 문제를 피한다. 기존 표시 자리는 유지하며 지리적 이동에 따른 작은 충돌은 가까운 자리로 보정한다. HP는 두 고정 캔버스 안에서 서로 겹치지 않게 놓고, 화면 밖 개체의 HP는 숨긴다. 장소 이름은 HP 영역을 피한다.
- 1초 백그라운드 정산 중 탐색/자동 버튼을 잠그거나 저장 알림을 반복하지 않는다. 같은 문구·지갑·패널은 다시 만들지 않으며 이동 남은 시간은 갱신한다. 저장 요청은 계속 직렬화하고 사용자 입력은 진행 중인 정산 뒤에 처리한다. 수동전투에서 다른 메뉴를 열어도 매 정산마다 전투 탭으로 강제 복귀하지 않도록 했다.
- 자동 체력을 100→10배로 변경했다. version 3/4/5 저장에서 팀·보관함·현재 적·대기 적의 체력 비율, 기절, UID와 PP를 보존한다. 수동은 1배다. 백업 검증은 현재 10배와 과거 100배를 모두 허용한다. 게임 RNG·공격 위력·명중·보상은 연출기에서 계산하지 않는다.

## 검증

- 최종 `npm run build` 후 전체 `npm test` 통과. 기존 엔진/경로/SQLite·IndexedDB/저장·초기화/정적 파일/두 고정 캔버스 검사와 새 재생기·에셋 검사를 수행한다.
- 지도 검사는 실제 타격 프레임과 효과 시점, 실패/무효, 카메라 이동·외부 2배 확대·두 방향의 HP 겹침 방지, 미확보 종, 기절·제거, 화면 밖 HP 숨김을 포함한다. 100배 구형 version 3/4/5의 팀·보관함·현재 적·대기 적을 10배로 변환하는 비율/UID/PP 보존과 반복 변환 방지도 검사한다. 지연된 정산 중 버튼·지갑·열린 패널이 유지되는지 UI 하네스로 확인했다.
- 새 엔진/재생기 검사는 최종타 뒤 기절/종료, 반격 순서, 0% 명중, 타입 무효, 회복/교체/상태 피해/반동/행동 불가/포획 성공·실패, 스냅샷 불변성, 중복/초기화/탭 복귀/오프라인/오류·시간 초과 잠금 해제를 포함한다.
- 에셋 검사는 45개 PNG 해시·크기, XML 프레임 수·시간·좌표, 8방향·앞/뒷방향, 명시된 대체 동작, 출처, file:// 메타데이터, 하위 경로와 로딩 재시도, 기술 효과 시점·빗나감/무효를 검사한다.
- 실제 인앱 브라우저에서 미리보기 로딩, 머드나기 공격 프레임 진행, 찌리비 뒷방향 발사, 맛보돈 피격, 샤프니아 대체 표시를 확인했다. 외부 원본 게임을 실행하거나 실제 휴대폰/GPS를 검사한 결과는 아니다. 브라우저의 추가 게임 검증 결과는 진행 기록에 남긴다.
- 별도 임시 주소의 브라우저 저장 공간에서 세로 360×800 지도, 가로 800×360 전투를 확인했다. 표식 중복 수정 후 야생 한 개 유지·HP 표시, 야생 경로 계산/이동/수동전투 진입, 명령 잠금→양쪽 HP/PP 갱신→명령 복구, 새로고침 시 HP/PP 복원, 마지막 공격→종료→보상 및 지도 복귀를 확인했다. 기존 사용자 저장의 초기화/변조 없이 별도 테스트 모험을 사용했다.

- 이번 3단계는 별도 임시 주소의 실제 인앱 브라우저에서 백업 복원, 수동→자동 22→220 및 3→30 체력 전환, 두 종의 실제 프레임 로딩을 확인했다. 세로 360×800에서 Shoot/Hurt 프레임과 투사체, 가로 800×360에서 HP 감소·종료 후 적 제거·승리 보상, 미확보 삐딱구리의 이미지 대체 표시를 확인했다. 재로딩과 방향 전환 후에도 정상 실행됐다. 실제 지도에서 HP 배치를 확인하고, 가까운 전투 그림의 겹침을 발견해 최소 표시 간격을 보강했다.
- 실제 공원까지 도보 경로를 만들고 출발한 뒤 Walk 프레임을 확인했다. 정산 전후 탐색/자동 버튼 활성 상태와 저장 문구가 유지되며 이동 시간이 갱신된다. 새 빌드의 브라우저 콘솔 오류는 발견되지 않았다. 실제 휴대폰·GPS·공개 Pages·지도를 직접 회전/드래그하는 제스처 검증은 이번 범위에서 하지 않았다. 테스트는 사용자 저장과 분리했다. 시각 기록은 `screenshots/combat-map-portrait-stage3.jpg`, `screenshots/combat-map-landscape-stage3.jpg`다.

## 지도 밀집 표시 보완

- 대기 포켓몬은 종별로 시간을 달리해 약 3초간 작은 걸음을 걷고 나머지 시간은 쉰다. 표시 이동량은 가로 최대 4/세로 최대 3 논리 픽셀이다. 전투·추적 대상과 이동 중 동행은 추가 배회를 하지 않으며 모션 감소 설정도 따른다.
- 실제 좌표와 MapLibre 외부 변환은 유지한다. 화면 안에서 트레이너와 동행/최대 5개 야생에 기본 간격을 두고, 아래 지도 버튼 공간도 피한다. HP는 다른 개체 그림도 피한다. 시설 기호가 캐릭터 위에 겹치면 그 기호를 숨기며 장소 목록에서는 계속 선택할 수 있다.
- 같은 위치에 모인 6마리·트레이너를 세로/가로와 네 모서리에 놓고, 배회·세계 좌표의 작은 이동·외부 확대·클릭 영역·지리 좌표 불변·모션 감소를 검사했다. 실제 브라우저에서 테스트 생성한 야생 5마리와 머드나기를 분리 표시하고 배회 프레임을 확인했다. 이동된 나룸퍼프를 눌러 올바른 정보 팝업이 열리는 것과 세로/가로 전환, 콘솔 오류 없음을 확인했다. 시각 기록은 `screenshots/map-pokemon-spacing-portrait.jpg`, `screenshots/map-pokemon-spacing-landscape.jpg`다. 이번 변경은 실제 휴대폰/GPS 검증 결과가 아니다.

- 결과 사건을 순서대로 표시하며 공격 이동/투사체/피격/HP 감소/기절을 보여 준다. 명령은 재생 중 잠그고 완료 뒤 복구한다. 메시지·체력만 갱신하며 무대와 이미지 요소는 매 프레임 재생성하지 않는다.
- 뒷모습은 확보된 PMDCollab 3종(749/940/915)의 북쪽 방향을 사용한다. 이는 본가 전투 전용 뒷모습 자료와 구분한다. 미확보 종은 정면을 대체 표시한다. Showdown 전용 PNG 다운로드는 현재 네트워크 연결 실패로 반입하지 않았다. 기존 제작자/라이선스 고지는 유지한다.
- UI 하네스에서 네 명령·네 슬롯·PP 표시·가방·교체 화면과 메뉴 탐색 무소모, 무대 노드 유지 및 기존 게임 전체 검사를 수행했다. 실제 브라우저 검증은 진행 결과에 별도로 남긴다.
