# 지도 자동전투·수동 턴제·공원 출현·저장

2026-10-21 적용. GitHub 업로드는 사용자가 직접 한다. 이 문서의 현재 규칙이 이전 3단계 밸런스 측정 당시 규칙보다 우선한다.

2026-10-22 연출 갱신: 전투 사실 기록과 순차 재생·표시 HP 보간·중복 방지·기절/종료 대기를 추가했다. 자동 체력은 사용자 요청으로 100배에서 10배로 변경했고 기존 저장의 남은 비율을 유지한다. 3종 지도 동작 연결 범위는 [전투 연출 구현 진행](COMBAT_IMPLEMENTATION.md)을 따른다.

## 전투

- 자동전투를 켜면 선택하지 않은 야생도 게임 위치에서 100m 안으로 접근했을 때 교전한다. 이동 중에는 1초 간격의 게임 시간 감지로 지나가는 대상을 찾는다. 선택한 대상이 범위 안에 있으면 우선한다.
- 자동 교전은 지도에 남는다. 동료·야생 위에 체력 막대와 수치를 표시하고, 기술 교환 때 실제 공격/발사·피격 프레임과 투사체·피해 또는 빗나감 효과(미확보 종은 기존 이미지 움직임)를 표시한다. 기존 6초 행동 간격을 사용한다.
- 양쪽 모두 기술 배치에서 PP가 남은 첫 공격 기술을 사용한다. 위력·명중·타입·공격/방어·우선도·속도·지원되는 특성/상태 효과는 기존 엔진을 적용한다. 해당 공격의 PP가 떨어지면 다음 공격 기술, 모두 소진되면 발버둥을 사용한다. 탐험 팀의 기술 관리에서 ↑/↓로 배치를 바꿀 수 있다.
- 지도 자동전투는 체력만 기본 수치의 10배다. 자동 포획·자동 도구 사용 정책은 공격 교환 방식으로 대체했다. 포획과 회복 도구는 수동전투에서 선택한다.
- 교전 중에는 이동을 멈추고 전투 종료 후 남은 경로를 재개한다. 전멸하거나 이동을 명시적으로 취소한 경우에는 재개하지 않는다. 전투 상태에 정지한 경로가 함께 저장된다.
- 수동전투에서는 기존 전투 화면을 열고 네 기술 슬롯·볼·회복 도구·교체·이탈을 선택한다. 아직 배우지 않은 슬롯은 비활성 상태로 표시한다. 행동을 누를 때 한 턴을 처리하며 6초 대기는 없다.
- 자동/수동 전환 시 팀·보관함·현재 적과 대기 적의 체력 배율을 함께 바꾼다. 현재 체력 비율과 기절·PP·개체 UID는 보존한다. 소수 체력은 내부 비율 보존에 사용하며 화면 수치는 올림 표시한다. 예전 version 3/4/5 저장도 호환한다.

## 공원 출현

- 공원 경계는 번들에 포함된 실제 OSM 폴리곤 자료로 먼저 준비한다. 외부 조회가 지연되어도 이 자료로 판정한다.
- 일반 가까운 출현은 10분마다 70%, 공원 안 또는 경계 150m 안은 2분마다 90%다. 먼 출현의 30분/25%는 그대로다.
- 공원 보정 상태에서는 실제 공원 내부의 서식지에 맞는 후보 좌표·종을 선택한다. 가까이 있어도 공원 내부 후보를 찾지 못하면 임의로 만들지 않는다. 확인되지 않은 공원 경계를 시설 중심의 원으로 대체하지 않는다.
- 구역 이동 시 다음 가까운 출현까지의 남은 비율을 새 주기로 환산한다. 메뉴의 위치·탐색에 현재 장소·주기·확률·공원 보정을 표시한다.
- 기존 테스트 ‘포켓몬 생성’ 버튼도 같은 후보 선택 규칙을 사용한다. 이 버튼은 대기·확률만 생략한다. 지도 야생은 전투 상대를 포함해 최대 5마리다(동행 포켓몬 제외). 새 개체가 실제로 생성되면 보호 대상 이외의 가장 오래된 개체를 교체한다. 확률 실패나 후보 위치 선택 실패만으로 기존 개체를 지우지 않는다. 이동·색이 다른 개체 규칙은 유지한다.

- 이동 목표와 전투 상대, 전투로 잠시 멈춘 이동 목표는 교체 및 수명 만료로 제거하지 않는다. 이동을 취소하거나 다른 목적지로 출발하면 기존 목표 보호를 해제한다. 보호된 개체는 수명이 지난 뒤에도 지도에 표시하고 도착 시 교전할 수 있다.
- 자연 출현과 테스트 생성 버튼 모두 같은 5마리 교체 규칙을 쓴다. 테스트 버튼은 가득 찼을 때도 오래된 비보호 개체를 교체한다. 전투 중인 적은 별도 전투 상태로 유지하며 새 출현으로 바뀌지 않는다. 마지막 기절 모션이 남아 있는 동안에도 화면의 총 야생 표식은 5개를 넘지 않는다.
- 새 출현부터 생성 시각을 저장한다. 이전 저장은 기존 만료 시각과 배열 순서로 출현 순서를 판단하며, 재개·복원 때 5마리보다 많으면 보호 대상을 남기고 오래된 개체부터 정리한다.

## 저장과 초기화

- 매 행동 및 화면이 열린 동안의 1초 주기 정산을 IndexedDB에 저장한다. 닫힌 동안의 시간은 다음 접속 때 기존 방식으로 정산한다. 수동전투는 명령 없이 턴이 진행되지 않는다.
- 메뉴 → 이 브라우저의 저장 → ‘지금 저장’, 저장 파일 내려받기/복원을 제공한다. 전투 체력·PP·기술 순서·대상·정지한 경로도 저장에 포함된다.
- ‘지금까지 정보 초기화’는 안내를 연 뒤 ‘모든 진행도 초기화 실행’을 눌러야 수행된다. 포켓몬·재화·배지·설정·위치·모험 기록을 지우고 체험 출발점에서 스타팅 선택으로 돌아간다. 공용 지도 데이터 캐시는 진행도와 별개다.
- 초기화는 저장과 사건 기록을 한 트랜잭션으로 처리한다. revision은 증가하며, 다른 탭의 오래된 요청은 거절한다. 같은 초기화 요청을 재전송해도 새 모험을 다시 지우지 않는다. 초기화 전 내려받은 백업은 이후 복원할 수 있다.
- 기기별 브라우저 저장이며 계정·클라우드 동기화나 서버 시각 보장은 없다. file://와 HTTPS 저장 영역은 별개다.

## 검증

빌드 후 전체 `npm test`를 수행한다. 실제 엔진의 100m 경계·지나가는 대상·수동 선택·첫 공격/PP·0%/100% 명중·체력 배율 전환·공원 내부/주변/외부 및 자연 출현을 검사한다. IndexedDB 전투 중 재열기·백업/복원·초기화 충돌/재전송·이전 백업 복구, 모의 DOM의 수동 네 기술 슬롯·체력 표시·초기화 확인/취소를 검사한다.

이 자동 검사는 실제 지도 애니메이션·휴대폰 터치·GPS의 시각/실기 확인을 대체하지 않는다. 이번 변경의 실제 브라우저·휴대폰 확인은 수행하지 않았다.
