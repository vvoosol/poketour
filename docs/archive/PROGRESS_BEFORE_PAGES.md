# 진행 기록

## 링크 공유용 접근 설정 완료

- 사용자의 외부 링크 실행 요청에 따라 기존 Sites 배포본의 접근 범위를 소유자 전용에서 public으로 변경했다.
- 공유 주소: `https://songpa-pixel-adventure.vvoosol.chatgpt.site`.
- Sites 재조회로 public/revision 2/active/기존 11버전 유지 확인.
- 로그인 쿠키·우회 인증 없이 메인 200과 JS/CSS 10개 200 확인. 미인증 API는 401로 계정별 저장의 인증 경계를 유지한다.
- 플레이에는 ChatGPT 로그인이 필요하다. 다른 사람의 실제 계정 로그인·플레이는 미검증이다.
- 코드 재배포나 기존 D1 데이터 변경 없이 접근 설정만 변경했다. GitHub 저장소는 비공개로 유지했다.
- 이번 소스 변경은 README와 공유 문서·진행 기록이며 앱 테스트를 재실행하지 않았다.

## HTML 진입점을 최상위로 이동

- 사용자 요청에 따라 실제 게임 HTML 원본을 `songpa-site/index.html`에서 저장소 최상위 `index.html`로 옮겼다.
- 빌드가 이 최상위 원본을 `songpa-site/dist/client/index.html`로 복사하도록 수정하고 두 파일 일치 검사를 추가했다.
- 변경 후 `npm run build`, `npm test` 전체 통과. 최상위 원본과 실제 제공 HTML의 일치 검사도 통과했다.
- HTML 파일 위치와 외부 공유용 실행 URL을 구분해 문서에 설명했다. 외부 공유 URL에는 인증·API·DB를 포함하는 호스팅 배포가 필요하다.

## 1단계 완료 — 개발 구조와 로컬 실행

- 브랜치: `codex/stage-1-local-development`.
- `index.html`, `src/client`, `src/shared`, `src/platform`, `public`, `scripts`, `tests`로 원본을 분리했다. 원본 폴더는 보존했다.
- 이동한 정적 자산 1,056개와 공유 엔진 모듈 3개가 원본과 SHA-256 기준 일치함을 확인했다.
- `npm run dev`: 깨끗한 빌드 후 루프백 HTTP + 동일 Worker API + 로컬 SQLite를 실행한다. `npm run preview`는 기존 빌드를 실행한다.
- 개발 사용자 `local-developer`와 `.local/game.sqlite`를 사용한다. 개발 인증은 Node 어댑터에만 있고 운영 모드에서는 시작이 거절된다.
- 플랫폼 계층으로 API 주소·정적 데이터·로그인 링크·위치·화면 복귀를 분리했다.
- 기존의 정적 자산 전체 base64 패키징을 제거했다. 웹 자산은 ASSETS 바인딩, 서버 데이터는 별도 JSON 의존성으로 연결한다. 보행 그래프는 서버에만 있다.

### 실제 검증

- 연속 두 번의 깨끗한 빌드 산출물이 동일했다. 빌드 전후 원본 파일 1,070개가 변하지 않았다.
- 전체 `npm test` 통과: 게임/기하 32개 + 도보 응답 2개, 시설 106곳 경로, SQLite Worker, 모의 DOM의 세 스타팅 흐름.
- 새 로컬 HTTP 검사 통과: 스타팅·저장·재전송, HTTP 서버/SQLite 재시작 후 복구, 개발 사용자 간 분리, 트랜잭션 롤백, Host/Origin/절대 대상 URL/본문 크기 제한, 비공개 파일 차단, 운영 개발 인증 거절.
- 플랫폼 API 주소·위치·복귀 어댑터와 산출물 해시 검사 통과.
- `npm run dev`로 실제 실행을 확인하고 첫 화면 HTTP 200을 확인했다. 브라우저에서는 지도와 체험 시작 저장까지 확인했다. 이후 브라우저 보안 정책이 로컬 탭 접근을 차단해 스타팅·새로고침의 추가 UI 검증은 하지 못했다. 해당 저장/복구는 로컬 HTTP 검사로 확인했다.
- 실제 휴대폰 GPS·터치, 독립 운영 로그인, 호스팅 배포는 이번 완료 범위에 포함하지 않는다.

### 크기 측정

- 종전 포함 자산으로 재구성한 Worker: 14,152,810 bytes, gzip 4,535,457 bytes.
- 새 브라우저 파일 합계: 4,073,015 bytes.
- 새 서버 JS 모듈 합계: 58,229 bytes, 개별 gzip 합계 21,902 bytes.
- 새 서버 JSON 합계: 8,025,777 bytes, 개별 gzip 합계 2,336,651 bytes.
- 새 서버 JS+JSON의 개별 gzip 합계는 2,358,553 bytes다. 이 측정은 실제 호스팅 도구가 생성하는 최종 번들 크기나 플랫폼 한도 통과를 보장하지 않는다.

실행 방법과 파일 지도는 `docs/ARCHITECTURE.md`에 기록했다. 다음 작업은 2단계 독립 운영 로그인과 실제 이동/게임 흐름 안정화다.

## 개발 계획을 5단계로 통합

- 사용자 요청에 따라 기존 10단계 프롬프트를 5단계로 요약했다.
- 새 순서: 개발 구조·로컬 실행 → 독립 로그인·게임 안정화 → 모바일 UI·콘텐츠 → 웹 배포·PWA → Android/iOS 앱·출시 준비.
- 각 단계에 실행 지시, 완료 기준, GitHub 커밋·푸시 규칙을 포함했다.
- 이미 완료한 원본 복사·GitHub 연결·기존 테스트 결과를 반영하고 README의 단계 수를 갱신했다.
- 이번 변경은 문서 정리다. 단계 구성과 문서 차이를 검토하며 게임 테스트는 재실행하지 않는다.
